# 本地折纸预览器（刚性折叠）

在浏览器中检查折痕图（crease pattern）对应的空间形态。无后端、无厚度、刚性面片模型；
折痕角不相容时直接报告“未收敛 / 自交 / 边界冲突”，不会把任意折痕图都宣称可折。

## 技术栈

- **Vue 3 + TypeScript**：折痕属性（山/谷/边界、角度、自动角）、选择同步、撤销重做
- **Rabbit Ear**：FOLD 格式读取与 `populate`（补全 edges_faces / faces_edges 等关联表）；
  仅提供边的输入由本项目的半边遍历（`src/fold/faceTrace.ts`）枚举面片
- **Three.js**：三维刚性面片渲染与点选
- **mathjs**：Levenberg–Marquardt 约束求解中的稠密线性方程（`lusolve`）
- **IndexedDB**：工程保存/打开/删除，全部数据留在本地浏览器

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run typecheck
bash scripts/run-all.sh   # 几何/求解/自交/存储回归脚本（无需浏览器）
```

## 运动路径（continuation）

多顶点联动时，同一目标折角可能对应不同运动分支，一步跳到求解终态会翻面甚至穿面。
工具从**平展状态逐步延续**（`src/fold/continuation.ts`）：

- 沿延续参数 t∈[0,1] 小步推进，固定边从 0 线性插值到目标，其余折痕为自动角；
- 每步以上一可靠步的解**热启动**，并用软正则把欠约束机构的零空间自由度
  拉回预测值，选择“折角变化最小”的平滑分支；山折边角度 ≥0、谷折 ≤0 防止跨符号跳变；
- 每步限制最大折角变化（默认 10°），自适应二分步长；
- 步的接受条件：闭环裂缝与求解残差都很小、**无面片穿透**、角度变化受控；
- 失去可行解时**停在最后可靠位置**（`infeasible` / `self-intersection`），
  取消计算时保留已接受的步，绝不展示突然翻面的终态；
- 平展态是构型空间的分岔奇点，首步做多初值**分支探测**；分支偏置滑杆影响探测方向。

路径是独立数据（`MotionPath`：逐步构型 + 指纹），**不修改工程源折痕**。
可以为同一目标运行多条路径、切换比较、拖动时间轴/播放、保存命名关键帧。
路径随工程存入 IndexedDB（自定义字段 `x_origami_preview_paths`）；
重载后用确定性几何重放，指纹与末态坐标校验“形态一致”。

**接触只针对无厚度模型**：除穿透相交外，检测器还分类“近共面/接触候选”
（表面最小距离 ≤ 包围盒 0.8%）。它只表示零厚度表面贴近，不含真实纸张的
厚度、材料分层或弹性，不推断叠层顺序，也不做材料仿真。

## 静态折叠模型与约定- 折痕两侧面片之间的**二面角 = π − 折叠角**；山折 M 取正旋转、谷折 V 取负，
  旋转轴沿父面环内的有向折痕边（右手定则）。
- 折叠计算：以面片为节点、折痕为铰链，按“自动角折痕优先”的并查集生成树做 BFS，
  每个子面的刚体变换 = 父面变换 × 绕铰链边的旋转（`src/fold/fold.ts`）。
- **共享边不能裂开**：非树（闭环）折痕边两端经两侧面片各自变换后必须重合，
  其距离作为闭合残差与“裂缝”展示。
- **约束求解**：勾选“自动角”的折痕为未知量，以闭环边闭合残差为目标做
  LM 阻尼最小二乘（前向差分雅可比、多初值），失败即报告 `约束未收敛`
  并列出最大裂缝边（`src/fold/solver.ts`）。
- **自交检测**：面片耳切三角化后，对不共享边的三角形对做 Möller 区间法 +
  共面退化测试；命中的面片标红并列出面片对（`src/fold/collision.ts`）。
- **不宣称可折**：诊断面板只有“当前构形满足刚性约束 / 未收敛 / 自交 / 边界冲突 / 不连通”，
  并且明确写出这只代表当前角度。

## 内置示例

1. **单折（书页）**：两刚性面共享一条山折，可改谷折、拖角度，共享边始终闭合。
2. **四折痕顶点（可折）**：扇区 60°/120° 交替（满足川崎），3M1V 指派；
   一条折痕设为自动角，求解器沿单自由度闭合曲线反解出约 60°。
   把指派改为 2M2V 后可从平展沿平滑分支延续。
3. **Miura 双顶点联动**：一条直折痕穿过两个度-4 顶点，两个顶点耦合；
   选一条折痕作为驱动目标角，延续路径 58 步平滑到达，适合对比不同分支。
4. **不一致边界（违反川崎）**：155°/45°/95°/65° 扇区，平角和不为 180。
   它仍可做非扁平的三维刚性折叠，但同时固定三条不相容折痕角时延续在平展附近停止，
   裂缝边紫色标出。

说明：川崎定理约束的是**扁平折叠态**（所有二面角 →0/π），不是任意三维刚性折叠；
工具在三维构形与过约束两种情形下分别给出“可折”与“失去可行解”。

## 交互

- 平面 SVG 与空间 3D 视图的**折痕 / 面片选择双向同步**（同一份 selection 状态）。
- 山/谷/边界/平展/未指派切换、0–180° 角度滑块、自动角勾选。
- 撤销/重做（Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y）：一次连续拖动产生一条历史；
  撤销角度修改时，山/谷标签、自动角标记与三维几何**一起恢复**。
- 导出 FOLD：始终保留 `vertices_coords / edges_vertices / faces_vertices` 与
  自定义命名空间 `x_origami_preview_crease_id`（折痕身份）；含折叠版本另存
  `edges_foldAngle` 与自动角标记。导入导出往返已由 `scripts/test-roundtrip.ts` 覆盖。
